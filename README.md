## Focus

I like projects that are small enough to understand end-to-end, but useful enough to keep around: static data tools, hardware data extraction, native desktop utilities, and interfaces that make raw numbers easier to reason about.

---

<sub>Most projects are intentionally lightweight: minimal dependencies, simple deployment, and data kept close to the code.</sub>
